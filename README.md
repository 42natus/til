# til

> Today I Learned 📑

A public collection of short write-ups on small things I learn in my day-to-day as a... learning developer.

The "TILs" are short markdowns that include a write-up and some example code that concisely explain concepts, syntax, commands, hacks, tips, etc. that I've recently learned — ideally within the same day I learn them. 

I am definitely not the owner/"comer-uper" of this idea. I first saw this from [adham90/til](https://github.com/adham90/til), who linked to [thoughtbot/til](https://github.com/thoughtbot/til) (who I think is the original idea-haver) and [jbranchaud/til](https://github.com/jbranchaud/til) as his original sources of inspiration.
